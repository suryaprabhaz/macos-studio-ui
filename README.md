# macOS Studio UI

An appearance customization extension and complete theme suite designed for VS Code, Cursor, Windsurf, and Code OSS.

## Key Features

- **Studio Theme Collection**: 6 handcrafted theme variants (Dark, Light, Midnight, Minimal, Glass-inspired, Classic).
- **One-Click Experience**: Instantly sets fonts, tab heights, smooth scrolling, and matching chrome colors.
- **Accent Palettes**: Switch accents dynamically across Blue, Purple, Pink, Orange, Green, and Graphite.
- **Native Control Center**: Access interactive controls directly from the activity bar.
- **Safe State Reversion**: Backs up your existing settings and restores them on demand without losing custom configurations.

## Included Themes

1. **macOS Studio Dark** - Professional deep graphite appearance with vibrant accents.
2. **macOS Studio Light** - Clean platinum appearance for daylight workflows.
3. **macOS Studio Midnight** - High contrast, deep space black canvas.
4. **macOS Studio Minimal** - Distraction-free setup hiding secondary editor chrome.
5. **macOS Studio Glass** - Refined translucent styling with layered contrast.
6. **macOS Studio Classic** - Traditional Aqua-inspired palette and syntax styling.

## Available Commands

- macOS Studio: Enable macOS Mode
- macOS Studio: Disable macOS Mode
- macOS Studio: Toggle macOS Mode
- macOS Studio: Select Preset
- macOS Studio: Open Settings
- macOS Studio: Restore Previous Appearance
